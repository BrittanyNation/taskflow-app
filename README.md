# Taskflow — Kanban Task Manager

A fully interactive kanban board built with pure HTML5, CSS3, and vanilla JavaScript. No frameworks, no build step — just clean, modern frontend code.

## Features

- **Drag & drop** — move cards between To Do, In Progress, and Done columns
- **Keyboard accessible** — arrow keys move focused cards between columns
- **Full CRUD** — add, edit, delete tasks with a modal form
- **Search & filter** — live search by title/description, filter by priority
- **localStorage persistence** — tasks survive page reloads, no backend needed
- **Live stats bar** — total, completed, and completion percentage
- **Priority system** — high/medium/low with color-coded visual indicators
- **Responsive** — stacks to a single column on mobile

## Tech

- HTML5 (semantic markup, `<template>`, `<dialog>` patterns)
- CSS3 (Grid, Flexbox, custom properties, animations)
- Vanilla JavaScript (ES6+ — modules pattern, event delegation, IntersectionObserver-free)
